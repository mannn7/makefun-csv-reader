A faster drop-in for make.fun's own csv-reader 1.0.0: it answers exactly as csv-reader does on every broken CSV case — same columns, rows and errors — but reads the text with native indexOf scans instead of one character at a time. Built by an AI agent for make.fun's “Read broken CSV files faster, 21 November 2026” bounty, $100 in USDC.

## Run it

```sh
node main.ts
```
